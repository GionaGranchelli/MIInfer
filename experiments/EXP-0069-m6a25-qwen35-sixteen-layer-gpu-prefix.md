# EXP-0069 — M6-A25 Qwen3.8 sixteen-layer stateful GPU prefix

## Question

Does the common ordered GPU executor continue to work through two complete
Qwen3.8 hybrid blocks, including the later recurrent states and full-attention
K/V caches?

## Candidate

Extended the A24 executor to 16 active layer references:

```text
L0–L2 Delta → L3 full attention
L4–L6 Delta → L7 full attention
L8–L10 Delta → L11 full attention
L12–L14 Delta → L15 full attention
```

The same `run_prefix()` implementation is used for all 16 layers. Layer
objects, recurrent state, attention caches, and output buffers are allocated
for the full prefix before the stateful loop; no per-position allocation was
introduced.

## Reference and workload

Model: `/home/fedora-workstation/models/Qwen3.8-27B-Q4_K_M.gguf`.

Reference fixture: `/tmp/m6a1-qwen38-reference`, generated by pinned llama.cpp
commit `c0bc8591e8815c63cb01dd3f051a8b0df02501c9`. The model SHA256 is
`7e78da5d7e3ae28d178121f58646953305f3e5bd3cb46f4a75584e8b6c6fe169`.

Positions P0, P1, P2, P4, P8, P16, P32, and P64 were externally checked. The
fixture provides output checkpoints for all 16 layers. Recurrent entry states
were checked for all 12 recurrent layers; K/V state was fingerprinted for all
four full-attention layers.

## Results

All 16 layer boundaries passed the external-reference envelope at every
reported position. The maximum absolute error was `0.306602` at L14/P0. The
largest relative RMS was `0.0156473` at L15/P1; the largest RMS was `0.0161831`
at L15/P1. No non-finite values were observed. Existing layer 3 and layer 7
errors remained unchanged from A24, demonstrating that later composition did
not alter the first two blocks.

## Stateful replay and reset

Entry and exit fingerprints were captured for the 12 recurrent states, all
four K/V caches, and all 16 layer outputs at each selected checkpoint. The
full prefix was then poisoned and reset through the real state initialization
path before replaying P0–P64.

Result: `poisoned_reset_replay=PASS`. A fresh-process replay of the audit also
matched the logical output/fingerprint stream; only the diagnostic CPU timing
line is intentionally variable.

## Decision

**KEEP / CLOSED.** A25 proves that the common GPU executor is not hard-coded to
the first two hybrid blocks: it composes four recurrent/full-attention groups
through P64 with independent later state and bounded external-reference error.

## Follow-up

Proceed to the 32-layer composition ladder using boundary checkpoints and
binary localization. Do not introduce a second block-specific executor.
