## Candidate

The audit fingerprints logical bytes only, with state type, layer, position,
dimensions, byte count, and SHA-256. It records entry and exit for each L0–L2
recurrent state, entry and exit for L3 K/V cache state, and hidden output after
each layer. A diagnostic logical state manifest reports aligned offsets and
sizes for recurrent delta state, convolution history, and the L3 K/V cache.

The reset audit uses the real host state reset path and tests:

* clean replay;
* full `0xFF` poison;
* full `0xA5` poison;
* recurrent-only poison;
* KV-only poison;
* a contaminating sequence followed by reset and replay.

The full fingerprint sequence covers contiguous positions `0..2`. Poison and
cross-sequence probes use position `0`, which is sufficient to detect stale
state immediately after reset while keeping the host diagnostic bounded.
