# EXP-0059 — M6-A15 Qwen3.8-27B layers 0–3 hybrid-block audit

## Status

KEEP — host correctness/composition audit complete. This is not a GPU
performance result; qwen35 recurrent HIP execution is not implemented yet.

## Question

Can the externally checked recurrent layers 0–2 and full-attention layer 3
compose through the complete stateful hybrid-block boundary at positions
0, 1, 2, 4, 8, and 16?

## Candidate

`miinfer-m6a15-qwen35-hybrid-block-audit` composes the real host executors:

```text
embedding
  → L0 recurrent DeltaNet
  → L1 recurrent DeltaNet
  → L2 recurrent DeltaNet
  → L3 full attention with RoPE and persistent K/V history
  → output projection, residual, FFN, and layer-3 output
```

The stateful run advances positions `0..16`. External checkpoints are checked
at positions `0, 1, 2, 4, 8, 16` using the existing A3/A4/A5 contracts.
Layer 3 is executed completely through its FFN and residual output; the audit
does not stop after attention scores or attention output.

At every position it emits logical SHA-256 fingerprints for:

* recurrent state before and after L0, L1, and L2;
* hidden output after L0, L1, L2, and L3;
* layer-3 K/V cache before and after the layer.

Fingerprints include state type, layer, position, logical dimensions, and
logical byte count. Padding and allocator slack are excluded.

## Correctness contract

Require the external-reference envelope at the selected checkpoint positions,
state continuity across every position, finite values, and unchanged K/V
append ordering. The A14 reset/replay contract remains the state ownership
authority; no old MIInfer byte-identical trajectory requirement is added.

## Decision

KEEP. Layers 0–3 now form a statefully composed, externally checked hybrid
block through the complete layer-3 output boundary. Entry/exit fingerprints
make recurrent-state, K/V-cache, and hidden-output divergence localizable at
each token position. No qwen35 GPU performance claim is made because the
recurrent HIP executor is still absent.
