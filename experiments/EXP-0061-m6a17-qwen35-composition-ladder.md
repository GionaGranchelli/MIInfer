# EXP-0061 — M6-A17 Qwen3.8-27B composition ladder

## Status

KEEP — one-token host composition ladder passed. This is not a GPU
performance result; qwen35 recurrent HIP execution is not implemented.

## Question

Does the generic qwen35 executor scale cleanly as the validated hybrid blocks
compose through 8, 16, 32, and 64 layers, without nonlinear per-layer runtime
or final-output correctness failures?

Reference fixture: `/tmp/m6a1-qwen38-reference`, generated by the pinned
llama.cpp reference used by M6-A1.

## Candidate

`miinfer-m6a17-qwen35-composition-ladder` executes the complete 64-layer
hybrid trunk for one token using recurrent layers at non-multiple-of-four
indices and full attention at layers `3, 7, ..., 63`. It checks the layer
outputs at the 8/16/32/64 boundaries, emits boundary hidden-state
fingerprints, computes final normalization and logits, and checks the external
greedy argmax.

A logical memory ledger reports model, recurrent state, convolution history,
full-attention KV, hidden workspace, and tracked bytes. It is a host planning
ledger, not a claim of measured GPU VRAM allocation.

## Correctness contract

The established M6-A7 stateful envelope is used for the layer checkpoints;
the external final-norm/logit envelope and position-zero greedy token remain
the final-output authority. A14–A16 provide the state reset and recurrent/KV
fingerprint contracts used by the composed layers.

## Decision

KEEP. The validated hybrid architecture composes through the full 64-layer
trunk with linear prefix scaling, correct boundary checkpoints, and matching
final argmax. The stateful 0–64 replay remains covered by M6-A7; this slice
adds explicit composition timing and boundary fingerprints. No qwen35 GPU
performance claim is made.

## Follow-up

The host composition ladder is complete. The next implementation milestone is
qwen35 recurrent HIP execution and a persistent GPU state/workspace plan;
after the full GPU path exists, start M6-B1 profiling and compare against the
pinned same-GGUF llama.cpp MI50 baseline.
