# EXP-0046 — M6-A4 Qwen3.8-27B full-attention layer

## Question

Can MIInfer reproduce one real Qwen3.8-27B full-attention layer, including Q/K/V projections, Q/K normalization, multi-axis RoPE, cached attention, the attention gate, output projection, residual, and FFN, from the production GGUF?

## Reference and baseline

The reference is llama.cpp commit `c0bc8591e8815c63cb01dd3f051a8b0df02501c`, using the local `Qwen3.8-27B-Q4_K_M.gguf` (`7e78da5d7e3ae28d178121f58646953305f3e5bd3cb46f4a75584e8b6c6fe169`). The fixture is generated by the M6-A1 exporter for prompt `hello`, with contiguous F32 checkpoints at positions 0 through 8 and the selected later positions.

Layer 3 is a full-attention layer in the verified 4-layer cadence. Its contract is:

```text
l_out-2
  -> RMSNorm
  -> Q + gate projection, Q/K normalization
  -> MRoPE sections [11, 11, 10, 0]
  -> causal GQA attention over layer-3 KV history
  -> sigmoid gate
  -> output projection
  -> residual, RMSNorm, Qwen FFN, residual
```

## Candidate

`miinfer-m6a4-qwen35-attention-layer` is a host-only tensor-first validator. It uses the real GGUF tensors and local reference helpers, while keeping GPU and production execution unchanged. The cached-attention history is reconstructed from the external layer-3 K/V checkpoints.

## Correctness gates

The validator compares real-model checkpoints for positions 0 through 8, including Q/K/V projections, normalized and RoPE'd Q/K, attention, gated attention, attention output, residuals, post-attention norm, FFN, and final layer output. It rejects non-finite values or tolerance violations.

## Results

All positions 0 through 8 passed. The largest observed absolute errors were:

| Checkpoint family | Maximum absolute error |
| --- | ---: |
| Q/QKV/K/V projections and norms | `3.15e-5` |
| MRoPE Q/K | `2.38e-5` |
| cached attention | `2.93e-3` |
| gated attention | `5.30e-4` |
| attention output/residual | `4.56e-3` |
| post-attention norm | `1.23e-3` |
| FFN | `2.11e-3` |
| final layer output | `4.84e-3` |

The small growth in the downstream F32/Q4_K reference comparisons is from
the local host dequantized/Q8_K matvec evaluation order. All values remained
finite and within the declared validator tolerances.

## Decision

**KEEP / M6-A4 complete for host bring-up.** The real layer-3 full-attention
path and its FFN tail pass the external fixture. This is a bring-up milestone
only; it does not claim GPU or full-model support.
