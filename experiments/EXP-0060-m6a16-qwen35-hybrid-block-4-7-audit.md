# EXP-0060 — M6-A16 Qwen3.8-27B layers 4–7 hybrid-block audit

## Status

KEEP — independent second hybrid block validated on the host. This is not a
GPU performance result; qwen35 recurrent HIP execution is not implemented.

## Question

Can the generic layer executor compose recurrent layers 4–6 and full-attention
layer 7 after the first layers 0–3 block, with correct state propagation and
the real preceding block output at every position?

Reference fixture: `/tmp/m6a1-qwen38-reference`, generated by the pinned
llama.cpp reference used by M6-A1.

## Candidate

`miinfer-m6a16-qwen35-hybrid-block-4-7-audit` executes both blocks in one
stateful host process:

```text
embedding
  → L0–L2 recurrent DeltaNet
  → L3 full attention and KV history
  → L4–L6 recurrent DeltaNet
  → L7 full attention and KV history
```

The second block receives the actual L3 output produced by the first block;
it does not substitute the embedding or rely on missing sparse `l_out-3`
checkpoints. The run advances positions `0..16`, including uncheckpointed
intermediate positions required to evolve recurrent and KV state correctly.

The audit emits logical SHA-256 fingerprints for L4–L6 recurrent state before
and after each layer, hidden outputs after L4–L7, and L7 K/V cache before and
after each token. Fingerprints include logical dimensions and byte counts and
exclude padding and allocator slack.

## Correctness contract

The existing external-reference envelope is used at positions
`0, 1, 2, 4, 8, 16` for the composed layer operations and recurrent state
inputs. State is advanced continuously for every position `0..16`, with L4–L6
recurrent state and L7 K/V history kept separate from the first block.

## Decision

KEEP. A second independent hybrid block now passes through the same generic
stateful composition path, including recurrent-to-recurrent propagation,
recurrent-to-full-attention transition, L7 KV mutation, and complete output
boundaries. The sparse fixture limitation is handled by composing L0–L3 in
the same run rather than skipping positions. No qwen35 GPU performance claim
is made.

## Follow-up

The next host bring-up step is a composition ladder through 8, 16, 32, and 64
layers with selected checkpoints, state fingerprints, reset/replay checks,
and a VRAM ledger. In parallel, qwen35 recurrent HIP execution remains the
prerequisite for M6-B1 MI50 performance measurement.
